# SteamPy 排序下拉框

功能默认关闭，通过 ScriptCat 菜单“排序下拉框”即时启停。开启后原生“最新 / 周销量 / 销量 / 折扣 / 价格”控件隐藏，替换为“字段下拉框 + 升序/降序按钮”两个控件；关闭时恢复原生控件，不改变当前排序结果。

## 字段与方向

| 字段 | 默认方向 | 查询参数 |
| --- | --- | --- |
| 最新 | 降序 | `createTime` |
| 周销量 | 降序 | `cdkCount` |
| 销量 | 降序 | `keyTx` |
| 折扣 | 升序 | `keyDiscount` |
| 价格 | 升序 | `keyPrice` |
| 实付价 | 升序 | `keyTxAmt` |
| 成交均价 | 升序 | `keyAveAmt` |
| 好评率 | 降序 | `rating` |

选择字段后使用该字段的默认方向；方向按钮再次点击即反转，与原生按钮的二次点击行为一致。所有字段都走 `searchForm` 参数，切换前会先退出已激活的高级筛选。

## 空值先验

`keyTxAmt`、`keyAveAmt`、`rating` 升序时接口把空值记录排在最前，这三个字段升序需要跳过空值区。本功能不额外发探测请求：

- 落点取空值比例估算页（默认 0.093，来自实测），并按记录的最后一个空值页向后推进。
- 只在升序且整页为空时记录空值页，比例只增不减，历史观测不会把落点拉回前面。
- 落点仍为空页时显示提示“本页无成交价数据，翻到下一页查看”，下次落点自动加一个比例步长。

空值行只隐藏对应卡片的 DOM，不修改 Vue 列表状态，因此与价格筛选互不覆盖。

实现位于 `src/lib/steampy/steampy-plus-sort-select.js`。
