# SteamPy 支付满减筛选

功能默认关闭，通过 ScriptCat 菜单“支付满减筛选”即时启停。手填满减门槛、减免金额和预估实付上限；关闭弹窗后保留条件。

商品页数默认为 1，从当前商品页起扫描，沿用页面已应用的高级筛选和排序，包括卡牌掉落条件，并沿用筛选栏「隐藏已拥有」（默认跳过已拥有）。弹窗不重复提供高级筛选选项。

扫描复用商品列表中的 `steamApp.type`；缺少类型时，通过 SteamPy 的 `searchByAppId` 接口查找同一 `appId` 的商品，保留已有的区域商品 ID。扫描在查询挂单前排除类型为 `dlc` 的记录，只查询类型为 `game` 的本体。类型无法确认的记录进入“其他结果”并显示诊断。

扫描按单价升序寻找有库存且达到门槛的挂单，以整数分计算减免后的预估实付，最低为 0。主表只显示已完成查询且有库存、达到门槛的结果，按预估实付升序排列，同价时按挂单价、原输入顺序排列。符合上限的结果标记“符合金额条件”；超限项显示具体差额，如“超出￥0.01”，保留这些接近目标的候选供选择。

无库存、未达门槛、查询失败等记录放入默认折叠的“其他结果”，标题显示记录数，展开后保留诊断原文。DLC 不进入结果表，进度显示已处理数、符合数、已拥有跳过数和已排除 DLC 数。停止查询时保留已完成结果；关闭或重新查询时清除旧结果。

结果只表示所填金额条件下的估算；商户、支付渠道、手续费及最终抵扣以收银台为准。

该功能不读取 SteamPy 站内 CDK 券或支付宝优惠信息；站内券查询 API 保留在 `src/lib/steampy/xboot-client.js`。
