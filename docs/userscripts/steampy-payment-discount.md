# SteamPy 支付满减筛选

功能默认关闭，通过 ScriptCat 菜单“支付满减筛选”即时启停。手填满减门槛、减免金额和预估实付上限；关闭弹窗后保留条件。

商品页数默认为 1，从当前商品页起扫描，沿用页面已应用的高级筛选和排序，包括卡牌掉落条件。弹窗不重复提供高级筛选选项。

扫描按单价升序寻找有库存且达到门槛的挂单，以整数分计算减免后的预估实付，最低为 0。结果只表示符合所填金额条件；商户、支付渠道、手续费及最终抵扣以收银台为准。

该功能不读取 SteamPy 站内 CDK 券或支付宝优惠信息；站内券查询 API 保留在 `src/lib/steampy/xboot-client.js`。
