# Z-Library 本地已有书籍标注

## 书单格式

每行一本，支持以下两种格式：

```text
中文名 | 作者
中文名 | 外语名 | 作者
```

导入会去除作者开头的 `(国家)` 或 `（国家）`，保留姓名内部的括号。按中文名和清理后的作者去重，新导入记录覆盖已有同键记录。外语名在导入、保存及重新打开编辑窗口后保留。

带 `---` 分隔符的文件名按文字系统区分中文名、外语名与作者，外语名保留在书单记录中。

## 匹配与标注

匹配时，书名与作者先将 Unicode 标点和符号替换为空格，再执行 NFKC、小写和空白规范化。书单保留原始文字。

中文名或外语名任一匹配，且作者匹配时，在封面左上角显示绿色“本地已有”。书名比较接受规范化后的相等值，也接受长度至少为 4 的短名称被长名称包含。

解析与匹配实现位于 `src/lib/zlib/owned-booklist.js`，页面标注实现位于 `src/lib/zlib/local-owned-mark.js`。
